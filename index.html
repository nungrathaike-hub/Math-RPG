LEVEL 1 • NUMBER MAGIC

Integers

Integers are whole numbers. They can be positive, negative, or zero. On a number line, numbers increase to the right and decrease to the left.

Example: −3 < 0 < 5

Key vocabulary: integer • positive • negative • zero • number line

➖

LEVEL 2 • OPERATION MAGIC

Addition & Subtraction of Integers

For the same signs, add the numbers and keep the sign. For different signs, subtract and keep the sign of the number with the larger value.

Example: −7 + 12 = 5

Key vocabulary: sum • difference • opposite • value

➕

LEVEL 3 • CRYSTAL OPERATIONS

Multiplication & Division of Integers

Same signs make a positive answer. Different signs make a negative answer. This rule works for multiplication and division.

Example: (−4) × (−3) = 12

Key vocabulary: product • quotient • positive • negative

✖️

LEVEL 4 • FRACTION SPELLS

Fractions & Decimals

A fraction shows part of a whole. Decimals show parts of one whole using place value. Fractions and decimals can show the same value.

Example: 0.75 = 75 hundredths = 3/4

Key vocabulary: numerator • denominator • decimal point • hundredths

🍰

LEVEL 5 • ALGEBRA SPELLS

Basic Algebra

Algebra uses letters to represent unknown numbers. Use the opposite operation to solve a simple equation and find the missing value.

Example: x + 8 = 15, so x = 7

Key vocabulary: variable • equation • solve • equal • inverse operation
