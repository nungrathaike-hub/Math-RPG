NUMBER MAGIC

Integers

Integers are whole numbers. They can be positive, negative, or zero. Think of a number line: numbers move right to become greater and left to become smaller.

Example: −3 < 0 < 5

Key words: positive • negative • zero • number line

➖

NUMBER MAGIC

Adding & Subtracting Integers

For the same signs, add the numbers and keep the sign. For different signs, subtract and keep the sign of the number with the larger value.

Example: −7 + 12 = 5

Key words: sum • difference • opposite • value

➕

NUMBER MAGIC

Multiplying & Dividing Integers

Same signs make a positive answer. Different signs make a negative answer. This rule works for multiplication and division.

Example: (−4) × (−3) = 12

Key words: product • quotient • positive • negative

✖️

PARTS OF A WHOLE

Fractions

A fraction shows part of a whole. The top number is the numerator. The bottom number is the denominator.

Example: 3/4 means 3 parts out of 4 equal parts.

Key words: numerator • denominator • equivalent • simplify

🍰

PLACE VALUE MAGIC

Decimals

Decimals show parts of one whole using place value. Digits after the decimal point show tenths, hundredths, and thousandths.

Example: 0.75 = 75 hundredths = 3/4

Key words: decimal point • tenths • hundredths • place value

🔢

ALGEBRA SPELLS

Basic Algebra

Algebra uses letters to represent unknown numbers. A letter such as x is called a variable.

Example: 3x means 3 × x

Key words: variable • expression • coefficient • term

🔮

ALGEBRA SPELLS

Simple Equations

An equation says two expressions are equal. Use the opposite operation to keep both sides balanced and find the unknown.

Example: x + 8 = 15, so x = 7

Key words: equation • solve • equal • inverse operation

⚖️

SHAPE MAGIC

Geometry Basics

Geometry studies shapes, lines, angles, and space. The perimeter is the distance all around a shape.

Example: Triangle perimeter = side 1 + side 2 + side 3

Key words: angle • side • vertex • perimeter
